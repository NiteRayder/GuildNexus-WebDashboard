NyxEclipse — Privacy Policy

Effective Date: July 19, 2026

1. Introduction

This Privacy Policy explains how NyxEclipse, a Discord bot developed by NyxNexus Development, collects, uses, stores, and protects data when users interact with the bot. By using NyxEclipse, you agree to the practices described in this policy.

NyxNexus Development prioritizes user privacy and aims to collect only the minimum data required for functionality, safety, and improvement.

2. Information NyxEclipse Collects

A. Automatically Collected Data

  • Server IDs
  • Channel IDs
  • User IDs
  • Message IDs (not message content)
  • Command usage logs
  • Moderation events (warnings, kicks, bans, mutes)
  • Bot configuration settings

B. Optional or Feature-Specific Data

Some features may require additional data, such as:

  • Temporary message content for moderation filters
  • AI-analysis of messages for automated moderation
  • User-submitted inputs for commands (e.g., forms, reports)

NyxEclipse does not store message content permanently unless explicitly stated for a specific feature.

3. How Data Is Used

NyxEclipse uses collected data to:

  • Operate bot commands and features
  • Provide moderation tools and automated enforcement
  • Improve performance, accuracy, and stability
  • Prevent abuse, spam, or malicious activity
  • Maintain server-specific configurations
  • Support AI-powered features such as content analysis or automated moderation

Data is never sold, shared, or used for advertising.

4. AI-Powered Processing

NyxEclipse may use AI systems to analyze content, detect violations, or generate automated responses.

AI processing may include:

  • Pattern recognition
  • Content classification
  • Automated moderation triggers
  • Utility responses or generated text

AI systems may make mistakes or produce imperfect outputs. Server staff should review automated actions when necessary.

5. Data Storage & Retention

NyxEclipse follows a minimal-retention philosophy:

  • Most data is temporary and cleared automatically.
  • Configuration data is stored until the server removes the bot.
  • Moderation logs may be retained only if the server explicitly enables logging features.
  • AI-related processing data is not stored beyond what is required for the feature to function.

If the bot is removed from a server, associated configuration data may be deleted.

6. Data Sharing

NyxNexus Development does not share user data with third parties except when:

  • Required by Discord's API
  • Necessary to operate bot features
  • Required by law, legal process, or security concerns
  • Preventing abuse, fraud, or attacks on the bot or its infrastructure

NyxEclipse does not integrate with external advertisers or data brokers.

7. Security Measures

NyxNexus Development implements reasonable security practices to protect data, including:

  • Access-restricted systems
  • Secure storage environments
  • Rate-limiting and anti-abuse protections
  • Regular maintenance and patching

However, no system is completely secure. You use NyxEclipse at your own risk.

8. Children's Privacy

NyxEclipse follows Discord's minimum age requirement of 13 years old. The bot does not knowingly collect data from children under 13.

9. Your Rights & Control

You may control your data by:

  • Removing NyxEclipse from your server
  • Resetting or deleting bot configurations
  • Disabling logging features
  • Contacting NyxNexus Development for questions or concerns

10. Changes to This Policy

NyxNexus Development may update this Privacy Policy at any time. Continued use of NyxEclipse after updates indicates acceptance of the revised policy.
