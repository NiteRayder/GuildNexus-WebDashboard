# GuildNexus image assets

Place dashboard branding assets here. Recommended structure:

- `branding/` - GuildNexus and NyxEclipse logos
- `icons/` - feature and navigation icons
- `guilds/` - optional server imagery/cache placeholders
- `backgrounds/` - optional dashboard backgrounds

SVG and optimized WebP/PNG are preferred. Keep large source artwork out of the production bundle.
